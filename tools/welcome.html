Cypache works

There are no sites yet. To add one, put its files in a folder named after its host, and restart Cypache:

  • /var/www/sites/example.com/public/ for static files, such as index.html
  • /var/www/sites/example.com/controllers/ and views/ for Python
  • systemctl restart cypache

The config is /etc/cypache/config.py, described in man cypache-config, and the sites' Python in man cypache-apps.
